# SurgeX

SurgeX is a premium, safety-focused e-hailing platform initially designed for Cape Town, South Africa.

## Vision

SurgeX aims to provide:

- Fair pricing for passengers
- Better earning opportunities for drivers
- Strong privacy and safety
- Secure payment processing
- Real-time trip tracking
- Driver and passenger verification
- Fraud prevention
- A simple and professional mobile experience

## Initial Vehicle Categories

- SurgeX
- SurgeX Comfort
- SurgeX Priority
- SurgeX Premium
- SurgeX XL

## Core Systems

- Passenger Mode
- Driver Mode
- Authentication
- Driver Verification
- Vehicle Verification
- Ride Matching
- Fare Calculation
- Cash Payments
- Card Payments
- R500 Weekly Driver Plan
- Voucher System
- Tips
- Safety Mode
- Panic / SOS
- Trip Sharing
- Payment Fraud Protection
- Driver Fraud Detection
- Passenger Cancellation Protection
- Driver Cancellation Protection
- Ratings
- Notifications
- Admin Dashboard

## Development Philosophy

SurgeX will be developed slowly and carefully.

Build → Test → Fix → Test → Commit → Continue.

Security, reliability, simplicity and safety come before speed.

## Initial Launch

Cape Town, South Africa.
