# SurgeX — Master Specification

## 1. Project Identity

**Project:** SurgeX  
**Type:** E-hailing / ride-hailing platform  
**Initial Launch:** Cape Town, South Africa  
**Platform:** Mobile-first  
**Primary Users:** Passengers and Drivers

## 2. Vision

SurgeX is designed to compete with major ride-hailing platforms while providing a premium, modern, safe and fair experience.

The main principles are:

- Fair pricing for passengers
- Better earning opportunities for drivers
- Strong safety
- Strong fraud prevention
- Secure payments
- Professional service
- Simple user experience
- Fast and reliable application performance

## 3. Application Structure

SurgeX will use one application with two primary modes:

### Passenger Mode

Used by passengers to:

- Create an account
- Request rides
- Select vehicle categories
- View fares
- Choose payment methods
- Track drivers
- Complete payments
- Rate drivers
- Tip drivers
- Use safety features
- Share trips
- Contact support

### Driver Mode

Used by drivers to:

- Register
- Submit verification documents
- Register vehicles
- Complete verification
- Go online/offline
- Receive ride requests
- Accept rides
- Complete rides
- View earnings
- Manage payments
- Use the R500 weekly plan
- Receive tips
- Use Driver Safety Mode
- Report incidents
- View ratings

## 4. Initial Vehicle Categories

### SurgeX

Standard ride category.

### SurgeX Comfort

More comfortable vehicles with additional space and comfort requirements.

### SurgeX Priority

Priority ride option for passengers who want priority pickup/service.

### SurgeX Premium

Premium vehicles such as qualifying BMW, Mercedes-Benz and Audi vehicles.

### SurgeX XL

Larger vehicles capable of carrying up to approximately six passengers, subject to applicable requirements.

## 5. Development Principles

SurgeX must be developed carefully and systematically.

### Development Cycle

Build → Test → Fix → Test → Commit → Continue

Every major feature must be tested before moving to the next feature.

The application should be:

- Mobile-friendly
- Fast
- Professional
- Simple
- Reliable
- Secure
- Easy to maintain

## 6. Design Direction

SurgeX should have an original visual identity.

The interface should use a modern dark-first design with strong contrast and clear information hierarchy.

The design may be inspired by successful international mobility applications, but SurgeX should not copy another company's protected branding, logos, assets or proprietary interface.

The goal is to create a unique SurgeX identity.
